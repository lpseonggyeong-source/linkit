2026-07-22
부록 "정산 계산 공식 안내서" 추가
별도로 만들어져 있던 정산 계산 공식 문서(결제금액이 상점·유보금·플랫폼수수료로 나뉘고, 다시 지사·총판·영업·운영사로 분배되는 전체 공식·사례·용어집)를 이 사용설명서와 같은 가이드 디자인으로 다시 만들어 09-settlement-formula.html로 추가했습니다. 좌측 사이드바에 "부록" 그룹을 새로 만들고, 표지와 정산관리 챕터에서 이 문서로 연결되는 링크를 달았습니다.
배경 — 정산 화면에 나오는 숫자가 어떤 계산으로 나온 것인지 더 깊이 알고 싶을 때 참고할 수 있는 별도 문서가 필요했고, 기존 문서의 디자인을 이 설명서의 최신 디자인과 통일해달라는 요청이 있었습니다.
2026-07-21
"상점 등록" 버튼 안내 문구 톤 완화
조직관리·상점관리 두 챕터에서 "이 버튼은 함정이니 사용하지 마세요" 식의 경고 문구를, "경로 설정 오류로 현재 번역되지 않은 화면으로 연결되며, 추후 업데이트로 수정될 예정"이라는 안내로 바꿨습니다.
배경 — 실제로는 알려진 경로 설정 버그이고 곧 고쳐질 예정이므로, 강한 경고보다는 담담한 안내가 더 정확하다는 피드백을 반영했습니다.
2026-07-21
대시보드 설명에서 기술적 세부사항 제거
대시보드 챕터의 "상점 선택 바" 설명 중 "선택하면 주소 끝에 ?search_member= 값이 붙으며 새로고침됩니다"라는 문구를 한국어·中文 버전 모두에서 삭제했습니다.
배경 — 실제로 상점을 선택해 화면이 바뀌는 결과만 알면 되고, URL 파라미터 같은 내부 구현 방식은 최종 사용자에게 불필요한 정보라고 판단했습니다.
2026-07-21
실제 화면 캡처 17장으로 교체
CSS로 재현한 목업 UI를 전부 걷어내고, 직접 제공받은 screen_captures/ 폴더의 실제 스크린샷 17장으로 바꿨습니다. 번호 콜아웃(●1 ●2 ●3)도 실제 화면의 버튼·필드·컬럼 위치에 맞춰 다시 배치해, 오른쪽 "사용 방법" 목록과 정확히 대응하도록 만들었습니다.
배경 — 처음에는 브라우저 자동화 도구가 없어 실제 화면을 캡처할 수 없었습니다("실제 화면을 캡쳐하지 않은 이유는?" 질문에 답한 뒤), 사용자가 직접 캡처한 이미지를 전달해주어 실사진 기반으로 전환할 수 있었습니다.
2026-07-21
Link it BA 가이드 스타일로 전면 재설계
좌측 고정 챕터 사이드바, 상단 고정 헤더, "CHAPTER N" 챕터헤더, 스텝필+2단(화면/사용법) 레이아웃, 스크롤에 따라 자동으로 하이라이트되는 우측 목차, 하단 이전·다음 챕터 이동바를 갖춘 구조로 다시 만들었습니다. 화면이 여러 개인 챕터(조직관리·상점관리·주문관리·정산관리·공지사항)는 탭으로 나누고, "하위 조직 등록", "정산처리 공통 절차" 같은 절차를 별도 섹션으로 세분화해 내용도 더 깊게 다뤘습니다.
배경 — 참고할 만한 다른 가이드 사이트(Link it BA 어드민 가이드)의 디자인이 더 체계적이라 판단해, 그 구조를 참고해 디자인을 고치고 내용도 더 발전시켜 달라는 요청이 있었습니다.
2026-07-21
최초 버전 제작 — 9개 파일
실제 CA 어드민(www.kcsvc.co.kr/bonbu_new/CA/)에 로그인해 대시보드부터 조직관리·상점관리·상품관리·주문관리·정산관리·공지사항·시스템설정까지 15개 화면 전체를 조사한 뒤, 표지 1개와 챕터 8개로 구성된 최초 버전을 만들었습니다. 페이지 상단의 한국어/中文 전환 버튼도 이때 처음 만들었습니다.
배경 — 중국 클라이언트가 실제로 사용할 CA 어드민의 사용설명서가 필요했습니다. 어드민 화면 자체는 이미 중국어 UI였지만, 검수·전달 과정에서 한국어도 함께 볼 수 있어야 해서 토글 방식의 이중언어 문서로 설계했습니다.
