서비스 개요

1.1 link it 플랫폼이란

link it은 셀러(인플루언서·개인 판매자)가 소셜 미디어 프로필 링크 하나로 여러 브랜드의 상품을 판매할 수 있도록 연결해주는 커머스 인프라 플랫폼입니다.

브랜드는 link it에 상품을 등록하고, 계약된 셀러에게 판매 권한을 부여합니다. 셀러는 각자의 링크를 통해 팬·팔로워에게 상품을 노출하고 판매 성과를 올립니다. 플랫폼은 주문·정산·정책을 중앙에서 관리하며, 모든 참여자에게 역할에 맞는 어드민 인터페이스를 제공합니다.

1.2 어드민 시스템 구성

link it의 어드민은 사용자 역할에 따라 세 개의 독립된 시스템으로 분리됩니다.

LA
Link it Admin

플랫폼 전체를 관리하는 내부 운영팀. 계약 업체·브랜드 승인, 플랫폼 정책을 담당.

CA
Company Admin

여러 브랜드를 보유한 계약 업체의 담당자. 소속 브랜드 전체와 셀러를 통합 관리,전체 정산을 담당.

BA
Brand Admin

단일 브랜드의 운영 담당자. 해당 브랜드의 상품·주문·디자인을 자체적으로 운영.

공통 기술 기반 CA와 BA는 동일한 shared.css / shared.js를 사용하며, 사이드바의 data-role="ca"|"ba" 속성 하나로 메뉴·배지·링크가 자동 전환됩니다. LA 어드민은 별도 admin.css / admin.js를 사용합니다.

2.3 CA가 별도 어드민을 가지는 이유

핵심 이유: CA는 "브랜드를 소유한 조직" 단위로 움직인다

BA는 하나의 브랜드만 운영하지만, CA는 동일 업체가 계약한 복수의 브랜드를 한 화면에서 통합 관리해야 합니다. 이 구조 차이가 메뉴·데이터 범위·UX 모두를 다르게 만듭니다.

① 크로스-브랜드 통합 뷰

대시보드·정산·셀러 화면에서 브랜드별 매출/성과를 나란히 비교할 수 있습니다. BA에서는 단일 브랜드 데이터만 제공되어 이 비교가 불가능합니다.

② 브랜드 등록 신청 권한

CA는 신규 브랜드를 link it에 직접 신청할 수 있습니다. 브랜드 담당자(BA)는 이미 승인된 브랜드를 운영할 뿐, 신규 브랜드를 만들 수 없습니다.

③ 셀러-브랜드 연결 관리

한 셀러가 여러 브랜드를 판매할 수 있는 구조에서, CA는 "어떤 셀러가 어떤 브랜드에 연결될지"를 설정하는 권한을 가집니다. BA에는 이 설정 화면이 없습니다.

④ 업체 단위 정산

정산은 "계약 업체 × 정산 기간" 단위로 발생합니다. CA는 소속 전체 브랜드의 미정산·정산중·정산완료 금액을 하나의 뷰에서 추적합니다. BA의 정산 화면은 브랜드 매출 요약 수준에 머뭅니다.

⑤ 공지 발신 범위

CA는 소속 브랜드 전체 또는 특정 브랜드를 선택해 공지를 발송할 수 있습니다. BA는 공지 수신만 가능하며 발신 화면이 제공되지 않습니다.

⑥ 디자인 편집 미제공

디자인 템플릿 및 편집은 브랜드 아이덴티티 영역이므로 BA 전속 기능입니다. CA는 디자인을 직접 편집하지 않고 브랜드 담당자(BA)에게 위임합니다.

3.2 공통 UI 패턴

레이아웃

  • · 고정 사이드바 (240px) + 스크롤 메인 영역
  • · 모바일: 햄버거 메뉴 → 오버레이 슬라이드
  • · 페이지 타이틀 + 서브타이틀 헤더

테이블 패턴

  • · 전체 선택 체크박스 (thead)
  • · 10개/페이지 기본, 페이지네이션
  • · 인라인 액션 버튼 (수정/상세/삭제)

필터·검색

  • · 셀렉트 드롭다운 + 텍스트 검색 조합
  • · 브랜드 선택 필터 (전 CA 페이지 공통)
  • · 검색/초기화 버튼 세트

모달

  • · 오버레이 배경 클릭·ESC로 닫기
  • · 크기: sm(360px) / md(560px) / lg(720px)
  • · 헤더·바디·푸터(저장/취소) 구조

SC-06 셀러 목록 ca-009-seller-list.html
페이지 목적

업체 소속 셀러와 브랜드 직접 등록 셀러를 통합 관리합니다. 셀러의 연결 브랜드, 판매 실적, 상태를 한눈에 확인합니다.

주요 기능
  • 소속유형 / 브랜드 / 상태 필터
  • 셀러명·ID 키워드 검색
  • 셀러 수정 모달 (정보 편집)
  • 셀러 상세 모달 (판매 실적 포함)
  • 셀러-브랜드 연결 페이지 바로가기

SC-07 셀러-브랜드 연결 관리 ca-012-seller-brand.html
페이지 목적

CA 전용 기능. 셀러와 브랜드의 판매 권한 연결 관계를 설정·해제합니다. 한 셀러는 여러 브랜드에 연결될 수 있습니다.

주요 기능
  • 셀러별 연결 브랜드 현황 조회
  • 브랜드 연결 추가 (셀러 선택 → 브랜드 체크박스)
  • 연결 해제 (브랜드별 × 버튼)
  • 연결 상태 필터 (연결됨/미연결)
⚠
이 화면은 BA에는 제공되지 않습니다. 셀러에게 브랜드 판매 권한을 부여·회수하는 권한은 CA(업체 단위)에게만 있습니다.
SC-08 정산 관리 ca-013-settlement.html
페이지 목적

업체 기준 정산을 조회합니다. 정산 단위: 계약 업체 × 정산 기간. 미정산·정산중·정산완료 금액을 KPI 카드로 즉시 파악합니다.

주요 기능
  • 정산 상태 요약 카드 4종 (미정산/정산중/정산완료/이번달순매출)
  • 정산기간 / 브랜드 / 정산상태 필터
  • 브랜드별 매출 테이블 + 셀러별 매출 테이블 (나란히)
  • 정산 상세 페이지 이동 링크

SC-10 공지사항 ca-016-notice.html
페이지 목적

LA로부터 수신한 공지를 열람하고, CA 관리자가 소속 브랜드를 대상으로 공지를 작성·발송합니다. 단일 페이지에서 목록-상세-작성을 SPA 방식으로 처리합니다.

주요 기능
  • 공지 목록 (중요 공지 배지 강조)
  • 공지 제목 클릭 → 상세 뷰 전환
  • 상세: 제목·작성자·날짜·본문·이전글/다음글 네비
  • 목록으로 돌아가기 버튼
  • + 글쓰기 버튼 → 작성 모달

SC-11 환경설정 ca-017-settings.html
페이지 목적

CA 계정의 로그인 정보와 업체 기본 정보를 확인하고 수정합니다.

주요 기능
  • 로그인 정보 카드: 아이디 표시 + 비밀번호 변경
  • 업체 기본 정보 카드: 업체명·이메일·연락처·계약만료일·계좌·예금주
  • 비밀번호 변경 모달 (현재/새/확인 입력 + 유효성 검사)
비밀번호 변경 모달 유효성
  • · 새 비밀번호: 8자 이상, 영문+숫자+특수문자 포함
  • · 확인 비밀번호: 새 비밀번호와 일치 여부 실시간 체크
  • · 눈 아이콘 토글로 비밀번호 표시/숨기기
