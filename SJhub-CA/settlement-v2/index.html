v2.7 — 목록 4페이지 정적 하드코딩 전환 (2026-07-16)

지사·총판·영업·대리점 목록(ca-013/019/020/021)을 settlement-v2.js 렌더링 대신 정적 HTML로 직접 하드코딩했습니다. 값은 기존 settlement-v2.js 로직(수수료·정산 예정 금액·거래 단위 KPI 집계)을 Node로 그대로 실행해 뽑아낸 스냅샷이라 이전 화면과 수치가 동일합니다. 사이드 네비게이션(shared.js)과 상세(ca-014)·유보금(ca-022) 페이지는 그대로 script 구동을 유지합니다. 목록 4페이지는 이름 검색(최소 인라인 스크립트)만 동작하고, 정렬·페이지네이션·엑셀 다운로드는 제거되었습니다. 주의: 이제 4페이지는 SALES 단일 원천이 아닌 고정 스냅샷이므로, 데이터 값을 바꾸려면 각 HTML을 직접 수정해야 합니다(v2.4~v2.6 규칙과 상충 — 클라이언트 요청에 따른 의도적 예외).

v2.4 — 테이블 데이터·공식 확정 (클라이언트 레퍼런스 테이블 2026-07-15)

클라이언트가 제공한 지사(分公司) 레퍼런스 테이블 기준으로 4개 정산 페이지의 데이터 값과 공식을 확정했습니다. 수수료 = 총 판매금액 × 수수료율, 정산 예정 금액 = 총 판매금액 − 수수료 (각 레벨 독립 계산). 지사 페이지는 레퍼런스 10행과 원 단위까지 일치하고, 총판·영업·대리점은 운영 스크린샷 시리즈(123,120 / 166,240 / …)를 사용합니다. 상세 내역은 목록 집계와 정확히 일치하도록 분해 생성됩니다(판매금액 합 = 총 판매금액, 수수료 합 = 수수료, 행 수 = 정산 건수). v2.3에서 열려 있던 "조직 페이지 정산 예정 금액의 의미"는 이 테이블로 매출 − 수수료로 확정되어 해소되었습니다. 유보금 차감은 목록 컬럼에 표시하지 않고(레퍼런스 레이아웃 준수) 유보금·예치금 관리에서 처리하며, 대상 대리점에는 ⚠/⏱ 뱃지로 연결됩니다.

v2.3 — 정산 4개 페이지 컬럼 개편 (클라이언트 요청 2026-07-15)

지사·총판·영업·대리점 정산 4개 페이지 공통 요청: ① '정산 금액' 컬럼명을 '수수료(手续费)'로 변경 ② '정산 예정 금액(应结算金额)' 컬럼 신설 — 정산 예정 금액 = 총 판매금액 − 수수료 ③ '정산 상태' 컬럼 삭제.

요청v2.3 구현
① 수수료 컬럼기존 '매출×수수료율' 금액 컬럼을 수수료로 명명 (대리점 = 운영사가 떼는 몫, 조직 = 차등 분배 몫). 정렬 지원
② 정산 예정 금액정산 예정 금액 = 매출 기준액 − 수수료 (대리점은 유보 적립 추가 차감 — v2.2 정책 유지). KPI·엑셀 다운로드에도 반영
③ 상태 컬럼 삭제목록 테이블에서 정산 상태 컬럼 제거. 보이지 않는 값을 기준으로 검색하지 않도록 상태 필터도 제거. 상태 변경·지급완료 워크플로우는 유지 — 개별 상태는 상세 화면의 기준일 상태 배너에서 확인

해소됨 (v2.4) — 조직 페이지 '정산 예정 금액'의 의미는 클라이언트 레퍼런스 테이블로 총 판매금액 − 수수료로 확정되었습니다.

v2.2 — 정산 방향·주기·취소 정책 반영 (담당자 피드백 2026-07-15)

피드백v2.2 구현
수수료 = 운영사가 떼는 몫대리점 지급액 = 결제원금 − 수수료 − 유보금. 대리점 정산 화면이 지급 관점으로 전면 재구성 (주기 도래 매출 / 취소 차감 / 수수료− / 유보 적립− / 지급 예정액)
유보금은 원금 기준유보 적립 = 결제 원금 × 유보율, 한도 도달까지 계속 차감. 원장·화면에 "원금 기준" 명시
조직 수수료는 수수료 풀 안에서남겨진 수수료로 조직 차등 지급 + 잔여분 = CA 마진. 검증 규칙 추가: 체인 최상위 조직율 ≤ 대리점 수수료율. 분배 보기 모달이 결제원금 100% 분해(파트너 수취 + 조직 분배 + CA 마진)를 표시
대상별 정산 주기전역 회차(일/주/월) 제거 → 정산 기준일 + 대상별 주기(D+N일). 오늘 정산 매출 = 각 대상의 주기만큼 이전 결제분. 목록에 주기·대상 결제일 컬럼 추가
당일 취소 확정분 차감기준일에 확정된 취소(이전 결제분)를 매출에서 차감 — 대리점 지급·조직 수수료 모두 동일 적용. 차감이 매출을 초과하면 음수 표시 + 익일 이월 경고
당일 주문·당일 취소 제외결제일 = 취소 확정일인 건은 매출·수수료·유보금 등 모든 계산에서 제외 (분배 보기에서 '계산 제외' 표기)

v2.1 — 유보금·예치금 개편 (운영 정책 반영)

운영 어드민에서 상점관리(대리점 목록)의 팝업으로 흩어져 있던 유보금·예치금을 정산관리의 탭 화면으로 이동했습니다. 두 항목의 목적은 동일합니다 — 정산 완료 후 결제 취소 발생 시를 대비한 금액.

항목운영 정책v2.1 구현

정책 확인이 필요한 가정

v2는 프로토타입 구현을 위해 다음을 가정했습니다. ① 수수료 분배는 포함형 차등(조직 몫 합 = 최상위 지사율)이며 대리점 수수료율은 별도 축 — 가산형이라면 분배 로직만 교체하면 됩니다. ② 유보금 정률은 회차 정산 금액 기준으로 보류(잔액 미차감), 정액은 지급완료 시 잔액에서 실제 차감. ③ 완료 취소는 사유 입력 시 무제한 허용 — 실제로는 권한 분리가 필요할 수 있습니다.
