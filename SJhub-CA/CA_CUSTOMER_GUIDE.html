1. 전체 운영 구조

SJ Hub 어드민은 운영사, 영업 조직, 대리점이 각자 다른 역할을 맡는 구조입니다.

구분의미주요 역할
CA본사 운영자가 사용하는 관리자 화면전체 조직, 대리점, 정산 현황을 총괄 관리
SA지사, 총판, 영업이 사용하는 정산 중심 관리자 화면소속 조직과 연결 대리점의 정산 현황 관리
BA대리점이 사용하는 판매 운영 화면상품 등록, 판매, 주문, 배송 관리
CA 운영사 ├─ 지사 │ ├─ 총판 │ │ ├─ 영업 │ │ └─ 대리점 │ ├─ 영업 │ └─ 대리점 ├─ 총판 ├─ 영업 └─ 대리점

지사, 총판, 영업은 모두 대리점을 직접 연결할 수 있습니다. CA가 대리점을 직접 등록해 관리할 수도 있습니다.

2. 요청사항 반영 현황

첨부된 CA 수정사항 메모를 기준으로, 각 요청이 현재 화면에 어떻게 반영되었는지 정리했습니다.

구분요청사항현재 반영 내용상태
조직 등록 영업 계정 등록 시 BA 계정 등록 정보와 동일한 필수 정보 입력 이름, 전화번호, 사업자 유형, 신분증 또는 사업자등록번호, 계좌번호, 은행명, 예금주 입력 구조로 정리했습니다. 완료
조직 등록 통신판매번호 항목 삭제 조직 등록 안내 기준에서 통신판매번호를 필수 항목으로 노출하지 않도록 정리했습니다. 완료
대리점 등록 대리점 등록 시 판매채널 항목 추가 대리점 기본 정보 입력 항목에 판매채널을 포함했습니다. 완료
대리점 등록 대리점 등록 시 상위 지사 또는 상위 조직 선택 지사, 총판, 영업 중 연결할 상위 조직을 검색하고 선택하는 방식으로 정리했습니다. 완료
대리점 등록 다량의 지사 등록을 고려해 검색 UI로 변경 상위 조직 검색 입력과 선택 흐름을 기준으로 안내했습니다. 실제 운영 데이터 수량에 맞춘 검색 조건은 추가 조정할 수 있습니다. 일부 반영
정산관리 정산관리 탭에 유보금 탭 추가 정산관리 메뉴에 유보금 정산 화면을 포함했습니다. 완료
정산관리 유보금 차감 및 유보금 D-day 설정 기능 유보금 관리 개념과 사용 목적은 반영했습니다. D-day 기준, 차감 방식, 자동 적용 조건은 운영 정책 확정이 필요합니다. 자료보충 필요
정산관리 정산일 표기 필요: 정산완료, 미정산, D-n일 정산 상태는 표시했습니다. D-n 표기를 위해서는 고객사별 정산 주기와 기준일 정책이 필요합니다. 자료보충 필요
정산관리 정산 페이지 KPI 추가: 오늘의 정산액, 정산 후 잔액 정산 요약 KPI 영역은 구성했습니다. 오늘의 정산액과 정산 후 잔액 계산 기준은 추가 정의가 필요합니다. 일부 반영
정산관리 본사 CA에서 정산 출금액 확인 CA 정산 화면에서 대상별 정산 금액과 필요 금액을 확인할 수 있도록 정리했습니다. 완료
정산관리 모든 정산 상세를 CA 페이지에서 확인 정산 목록에서 상세 내역 보기로 판매 내역과 정산 근거를 확인하는 흐름을 반영했습니다. 완료
정산관리 고객사마다 다른 정산일, 오늘 정산 대상, 정산 금액, 수수료 비율 확인 대상별 정산 금액과 수수료율 확인 구조는 반영했습니다. 고객사별 정산일 정책과 정산 대상 산정 기준은 추가 자료가 필요합니다. 자료보충 필요
정산관리 정산금을 어떻게 결제 또는 송금할 수 있는지 확인 현재 문서에는 정산 확인과 상세 조회 중심으로 안내했습니다. 실제 송금 방식, 수동/자동 처리 여부, 결제 승인 절차는 정책 확정이 필요합니다. 자료보충 필요
정산관리 결제 내역 영수증 또는 엑셀 다운로드 확인 엑셀 다운로드 흐름은 정산 화면에 포함했습니다. 영수증 양식과 다운로드 범위는 추가 정의가 필요합니다. 일부 반영

상태 기준: 완료는 현재 화면과 안내서에 반영된 항목, 일부 반영은 기본 흐름은 있으나 운영 기준 확정 후 보완할 항목, 자료보충 필요는 정책이나 계산 기준이 추가로 필요한 항목입니다.

3. 조직 관리

조직 관리는 CA 아래에서 운영되는 지사, 총판, 영업을 관리하는 메뉴입니다.

조직 리스트

전체 영업 조직을 한눈에 보고, 하위 조직 등록이나 대리점 연결을 처리합니다.

항목설명
구분지사, 총판, 영업 중 어떤 조직인지 표시
조직 위계해당 조직이 어느 상위 조직 아래에 있는지 표시
상위 조직바로 위에 연결된 조직
수수료율해당 조직에 적용되는 수수료 비율
연결 대리점해당 조직에 연결된 대리점 수
관리하위 조직 등록, 대리점 등록, 상세, 수정 기능

등록 하기

새로운 영업 조직 계정을 등록하는 화면입니다. 이름, 전화번호, 사업자 유형, 신원 또는 사업자 정보, 정산 계좌 정보를 입력합니다.

4. 대리점 관리

대리점 관리는 실제 상품을 등록하고 판매하는 대리점 정보를 관리하는 메뉴입니다. 기존에 브랜드, 고객사, 파트너 등으로 불리던 대상을 모두 대리점 기준으로 관리합니다.

계약 대리점 목록

CA와 계약된 대리점 목록을 확인하고 승인 상태, 신청 출처, 관리 주체, 상품수, 주문수, 매출을 조회합니다.

대리점 등록 신청

새 대리점을 등록하고 지사, 총판, 영업 중 연결할 상위 조직을 지정합니다.

구분입력 내용
대리점 기본 정보대리점명, 설명, 카테고리, 판매채널
상위 조직 연결지사, 총판, 영업 중 연결할 조직
사업자 정보상호명, 사업자등록번호, 대표자명, 사업장 주소
담당자 정보담당자명, 이메일, 연락처, 직책
정산 정보은행명, 계좌번호, 예금주, 정산 주기
배송/반품 정보배송비, 무료배송 기준, 반품/교환 배송비

5. 정산관리

정산관리는 지사, 총판, 영업, 대리점의 정산 금액과 상태를 확인하는 메뉴입니다.

메뉴설명
지사 정산지사별 정산 금액과 상태 확인
총판 정산총판별 정산 금액과 상태 확인
영업 정산영업별 정산 금액과 상태 확인
대리점 정산대리점별 정산 금액과 상태 확인
유보금 정산정산 전 보류하거나 차감할 금액 관리
정산 상세 내역정산 대상의 판매 내역과 정산 근거 확인

정산 목록에서 확인하는 정보

총 정산 수, 정산 완료 건, 정산 필요 건, 정산 총액, 정산 완료 금액, 정산 필요 금액을 확인합니다.

상세 내역 보기

정산 목록의 상세 내역 보기 버튼을 누르면 판매처, 판매 상품, 주문번호, 판매 일자, 판매금액, 수수료, 정산 금액, 정산 상태를 확인할 수 있습니다.

6. 자주 쓰는 업무 흐름

새 조직을 등록할 때 조직 관리 > 등록 하기에서 기본 정보와 정산 계좌 정보를 입력한 뒤 조직 리스트에서 확인합니다.
조직에 대리점을 연결할 때 조직 리스트에서 연결하려는 지사, 총판, 영업을 찾고 대리점 등록 버튼을 누릅니다.
대리점 현황을 확인할 때 대리점 관리 > 계약 대리점 목록에서 승인 상태, 신청 출처, 대리점명으로 검색합니다.
정산 금액을 확인할 때 정산관리에서 대상을 선택하고 조회 기간을 설정한 뒤 상세 내역 보기에서 근거를 확인합니다.

참고: 현재 권한설정 기능은 내부 운영 기준이 확정된 뒤 다시 반영할 예정입니다. 화면의 일부 데이터는 예시 데이터이며, 실제 운영 시에는 실데이터와 연동됩니다.
