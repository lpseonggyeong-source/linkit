상품 진열
1
상품 기본 정보 & 가격 설정
상품명·카테고리·대표 이미지(최대 7장)를 입력하고, 판매 상태와 판매가·공급가·할인가를 설정합니다.
1
2
3
4
상품 기본 정보
1
상품명 입력 (최대 100자, 필수)
고객 검색과 목록 표시에 직접 사용됩니다. 정확하고 명확하게 입력하세요.
2
카테고리 선택 (1Depth → 2Depth)
상위 카테고리를 먼저 선택하면 하위 카테고리 목록이 활성화됩니다. 상품 목록 필터에 반영됩니다.
가격 설정
3
판매 상태 선택 & 판매가 입력 (필수)
판매중·판매중지·품절 중 현재 상태를 선택합니다. 판매가는 필수 항목입니다.
4
공급가·할인가 입력 → 할인율 자동 계산
공급가는 원가 관리용, 할인가는 실제 할인 금액입니다. 할인가 입력 시 스토어에 할인율이 표시됩니다.
2
판매 설정 & 배송 설정
재고 수량·기간 판매·셀러 계정을 설정하고, 기본 배송비와 지역별 추가 배송비를 입력합니다.
1
2
3
4
판매 설정
1
시작 재고 수량 입력
등록 시점의 초기 재고 수량입니다. 옵션이 있는 경우 옵션 설정에서 조합별로 재고를 별도 설정합니다.
2
기간 판매·셀러 계정 설정
특정 기간에만 판매할 경우 시작일·종료일을 입력합니다. 셀러 계정 체크박스로 이 상품을 노출할 스토어를 선택하세요.
배송 설정
3
기본 배송비 입력 (무료배송: 0원)
무료배송 기준 금액과 기본 배송비를 설정합니다. 고정 배송비라면 0원을 입력하세요.
4
제주·도서산간 추가 배송비 입력
지역별 추가 배송비가 없으면 0원으로 입력합니다.
3
옵션 설정 & 추가 옵션
옵션명과 값을 입력하면 조합이 자동 생성됩니다. 각인 문구 등 고객이 직접 입력해야 하는 항목은 추가 옵션에서 설정합니다.
1
2
3
4
옵션 설정
1
옵션명·옵션값 입력
옵션명(예: 색상)과 옵션값(예: 레드/블루)을 입력하면 조합이 자동 생성됩니다. 복수의 옵션명으로 더 세분된 조합을 만들 수 있습니다.
2
조합 테이블 재고·추가 비용 설정
자동 생성된 조합별로 재고 수량과 추가 비용을 개별 입력합니다.
3
[저장]으로 옵션 적용
옵션 설정 완료 후 반드시 [저장]을 클릭해야 반영됩니다.
추가 옵션
4
고객 직접 입력 항목 추가 (선택)
각인 문구·전달 사항 등 구매 시 고객이 입력해야 하는 항목입니다. 필요 없으면 건너뛰세요.
4
상세 페이지 설정 & 업로드(저장)
에디터 또는 이미지 업로드로 상세 페이지를 작성하고, 우측 하단 [업로드] 버튼으로 최종 등록합니다.
1
2
3
4
상세 페이지 설정
1
[에디터 이용] 탭에서 서식 편집
텍스트·이미지·링크를 조합한 상세 페이지를 만듭니다. 글씨체·굵기·줄간격 등 서식을 자유롭게 설정하세요.
2
[이미지만 등록] 탭으로 이미지 업로드
미리 디자인된 상세 이미지 파일이 있다면 이 탭을 이용하세요. 여러 장을 순서대로 등록할 수 있습니다.
3
상품 특징·사용법·주의사항 작성
상세 정보는 고객 구매 결정에 핵심 역할을 합니다.
업로드(저장) 버튼
4
우측 하단 [업로드]로 최종 등록
모든 항목 작성 완료 후 [업로드]를 클릭해야 상품이 등록됩니다. 클릭 전 페이지를 벗어나면 입력 내용이 모두 사라집니다.
⚠️ [업로드]를 누르지 않으면 저장되지 않습니다.
1
기본 화면 — 카테고리 미선택
페이지 최초 진입 시 좌측에 최상위 카테고리 목록만 표시되고, 우측 패널에는 "상위 카테고리를 선택하세요" 안내가 표시됩니다.
1
2
3
사용 방법
1
좌측 패널 최상위 카테고리 목록 확인
등록된 모든 최상위 카테고리가 나열됩니다. ⠿ 핸들을 드래그하면 스토어 노출 순서를 변경할 수 있습니다.
2
최상위 카테고리 클릭 → 하위 카테고리 관리
클릭하면 빨간 테두리로 선택 표시되고, 우측 패널에 해당 하위 카테고리 목록이 나타납니다.
3
우측 패널 안내 메시지 확인
카테고리 선택 전에는 "상위 카테고리를 선택하세요" 안내가 표시됩니다.
2
카테고리 선택 — 활성 상태
카테고리를 클릭하면 빨간 테두리로 강조되고 우측에 하위 카테고리 목록이 나타납니다. 순서 변경·노출 토글·편집·삭제를 여기서 관리합니다.
1
2
3
사용 방법
1
⠿ 핸들 드래그로 순서 변경
⠿ 아이콘을 클릭&드래그하면 스토어 노출 순서가 변경됩니다. 변경 즉시 저장됩니다.
2
[+ 하위 카테고리 추가]로 카테고리 생성
버튼을 클릭하면 추가 모달(3번)이 열립니다. 트리 하단 점선 버튼으로도 동일하게 열 수 있습니다.
3
토글·편집·삭제 아이콘으로 항목 관리
토글(ON/OFF)로 스토어 노출 여부를 즉시 전환합니다. ✏ 편집으로 이름 수정, 🗑 삭제로 삭제 모달(4번)을 호출합니다.
💡 상품이 0개인 카테고리는 자동으로 비활성 표시됩니다.
3
하위 카테고리 추가 모달
[+ 하위 카테고리 추가] 클릭 시 오버레이로 표시됩니다. 카테고리명(필수)과 상위 카테고리를 선택 후 [저장]하면 목록에 즉시 추가됩니다.
1
2
3
사용 방법
1
카테고리명 입력 (필수)
비어 있으면 [저장]을 누를 수 없습니다.
2
상위 카테고리 선택
기본값은 현재 선택된 상위 카테고리로 자동 설정됩니다.
3
[저장]으로 생성, [취소]로 닫기
[저장]을 클릭하면 카테고리가 생성되어 목록에 즉시 추가됩니다.
4
카테고리 삭제 확인 모달 — 포함 상품 처리 선택
🗑 아이콘 클릭 시 표시됩니다. 포함된 상품의 이동 카테고리를 선택해야만 삭제가 가능합니다.
1
2
3
사용 방법
1
삭제 대상·포함 상품 수 확인
삭제 대상 카테고리명과 포함 상품 수가 표시됩니다. 상품이 있으면 이동 처리가 필요합니다.
2
이동 카테고리 선택 & 체크박스 활성화
드롭다운에서 상품을 이동할 카테고리를 선택합니다. 체크 시 상품이 일괄 이동되고, 미체크 시 카테고리만 삭제됩니다.
3
[삭제 및 이동]으로 완료, [취소]로 중단
삭제와 상품 이동이 동시에 실행됩니다.
⚠️ 카테고리 삭제는 되돌릴 수 없습니다. 연결 상품의 이동 대상을 반드시 확인 후 진행하세요.
1
메인 화면 — 상품 목록
등록된 전체 상품을 조회하고 필터·검색·편집·삭제 등 주요 작업을 실행하는 화면입니다.
1
2
3
사용 방법
1
상태·브랜드·카테고리 필터로 상품 검색
판매 상태·브랜드·상위/하위 카테고리를 선택하고 상품명으로 검색합니다. 조건을 조합해 정밀하게 추려낼 수 있습니다.
2
테이블 컬럼으로 상품 정보 확인
No.·대표사진·제품명·가격·기간판매·옵션·판매여부·재고·판매수·링크·등록일·관리 컬럼으로 구성됩니다. [링크 복사]로 스토어 상품 URL을 복사할 수 있습니다.
3
관리 열 아이콘으로 상품 처리
[관리]→옵션 팝업 / [상품복사]→복제 확인 / ✏→편집 모달 / 🗑→삭제 확인
2
판매 상태 변경 드롭다운
각 행의 판매 상태 배지를 클릭하면 드롭다운이 열립니다. 새 상태를 선택하면 별도 저장 없이 즉시 변경됩니다.
1
2
3
사용 방법
1
판매 상태 배지 클릭
목록에서 상태를 변경할 상품 행의 판매 상태 배지를 클릭합니다.
2
드롭다운에서 새 상태 선택
판매중·판매중지·품절 중 변경할 상태를 선택합니다. 선택 즉시 스토어에 반영됩니다.
3
목록 배지 즉시 업데이트
별도 [저장] 버튼 없이 바로 반영됩니다.
3
옵션 관리 모달 — 조합별 재고·추가 비용 수정
[관리] 버튼 클릭 시 열립니다. 옵션 조합별 재고 수량과 추가 비용을 확인하고 수정합니다.
1
2
3
사용 방법
1
옵션명·값 확인
팝업 상단에 색상·사이즈 등 옵션명과 값 목록이 표시됩니다.
2
조합 테이블 재고·추가 비용 수정
자동 생성된 조합별로 셀을 직접 클릭해 재고와 추가 비용을 수정합니다.
3
[닫기]로 모달 닫기
수정 내용 저장은 편집 모달(4번)에서 진행합니다.
4
상품 편집 모달 — 전체 정보 수정
✏ 편집 아이콘 클릭 시 열립니다. 상품명·가격·카테고리·상세 페이지를 수정하고 [저장]합니다.
1
2
3
사용 방법
1
상품명·가격 정보 수정
상품명(필수)·판매가(필수)·공급가·할인가를 수정합니다.
2
[변경]으로 카테고리 수정
카테고리 옆 [변경] 버튼을 클릭하면 카테고리 변경 모달(5번)이 열립니다.
3
상세 페이지 수정 후 [저장]
에디터/이미지 탭으로 상세 내용을 수정하고 [저장]을 눌러야 반영됩니다. [닫기]·✕로 닫으면 변경사항이 사라집니다.
5
카테고리 변경 모달 — 1Depth → 2Depth 선택
편집 모달의 [변경] 버튼 클릭 시 열립니다. 상위 → 하위 순으로 선택하고 [적용]하면 편집 모달에 반영됩니다.
1
2
3
사용 방법
1
1Depth 카테고리 선택
상위 카테고리를 클릭하면 선택 표시됩니다.
2
2Depth 카테고리 선택
1Depth 선택 시 오른쪽에 하위 목록이 표시됩니다.
3
[적용]으로 편집 모달에 반영, [취소]로 닫기
편집 모달에서 [저장]까지 눌러야 최종 저장됩니다.
6
상품 복사 확인 모달
[상품복사] 클릭 시 나타납니다. 모든 정보를 그대로 복제해 신규 상품을 빠르게 만들 수 있습니다.
1
2
3
사용 방법
1
복사 안내 메시지 확인
이미지·가격·옵션·상세 등 모든 정보가 그대로 복제됩니다. 복제 후 목록에서 개별 수정이 가능합니다.
2
[취소]로 작업 중단
[취소]를 클릭하면 모달이 닫힙니다.
3
[복사하기]로 상품 복제
목록 하단에 복제된 상품이 추가됩니다. ✏ 편집으로 바로 수정하세요.
7
상품 삭제 확인 모달 — 영구 삭제 전 최종 확인
🗑 아이콘 클릭 시 나타납니다. 삭제한 상품은 복구할 수 없으며 스토어에서도 즉시 제거됩니다.
1
2
3
사용 방법
1
삭제 대상·복구 불가 안내 확인
올바른 상품인지 반드시 확인하세요. 삭제 후에는 복구가 불가능합니다.
2
[취소]로 삭제 중단
목록으로 돌아옵니다.
3
[삭제]로 즉시 영구 삭제
스토어에서도 즉시 제거됩니다.
⚠️ 삭제된 상품은 복구할 수 없습니다.
1
페이지 처음 — 디폴트 화면
상품 진열 메뉴를 처음 열면 이 화면이 나타납니다. 먼저 좌측 드롭다운에서 진열할 섹션을 선택해야 작업을 시작할 수 있습니다.
1
2
3
사용 방법
1
좌측 드롭다운에서 섹션 선택
처음에는 "섹션을 선택해주세요"가 표시됩니다. 드롭다운에서 진열할 섹션을 선택해야 우측 패널이 활성화됩니다.
2
진열 상품 없음 → 빈 화면
섹션을 선택했지만 진열된 상품이 없으면 빈 화면이 나타납니다. 우측 패널에서 상품을 추가해 채우세요.
3
우측 패널 비활성 — 섹션 선택 필요
섹션이 없다면 먼저 상점 관리(4챕터)에서 섹션을 생성해야 합니다.
💡 섹션이 없다면? 상점 관리(Ch4) → 상점 선택 → 섹션 생성 후 돌아오세요.
2
섹션 선택 후 — 진열 목록 확인 & 관리
섹션을 선택하면 현재 진열된 상품이 표시됩니다. 순서 변경·공개/비공개 전환·삭제를 여기서 합니다. 반드시 [적용]을 눌러야 저장됩니다.
1
2
3
사용 방법
1
⠿ 드래그로 노출 순서 변경
드래그로 순서를 바꾸세요. 변경 후 반드시 [적용]을 눌러야 저장됩니다.
2
공개/비공개 배지로 노출 전환
배지 클릭으로 노출 여부를 토글합니다. 비공개로 설정해도 목록에는 남아 나중에 다시 공개할 수 있습니다.
3
[적용]으로 변경사항 저장
순서·공개 전환·🗑 삭제 모두 [적용]을 눌러야 반영됩니다.
⚠️ [적용]을 누르지 않으면 저장되지 않습니다.
3
추가할 상품 찾기
[+ 상품 추가]를 누르면 우측 패널이 활성화됩니다. 카테고리 드롭다운과 상품명 검색창으로 원하는 상품을 빠르게 찾으세요.
1
2
3
사용 방법
1
[+ 상품 추가] 클릭
클릭하면 우측 상품 검색 패널이 활성화됩니다.
2
카테고리 드롭다운으로 범위 축소
우측 상단 카테고리 드롭다운에서 분류를 먼저 선택하면 검색 범위가 좁혀집니다.
3
상품명 검색창으로 상품 검색
키워드 입력 후 [검색]을 클릭합니다. 카테고리와 검색을 조합하면 더 빠르게 찾을 수 있습니다.
4
진열할 상품 선택하기
체크박스로 진열할 상품을 선택합니다. 여러 상품을 한번에 선택할 수 있으며, 이미 진열된 상품은 자동으로 중복 추가되지 않습니다.
1
2
3
사용 방법
1
헤더 체크박스로 전체 선택/해제
목록 상단 헤더 체크박스를 클릭하면 현재 보이는 상품을 모두 선택합니다.
2
개별 체크박스로 상품 선택
이미 진열된 상품은 자동으로 중복 추가되지 않습니다.
3
1개 이상 선택 후 [추가] 클릭
선택하면 [추가] 버튼이 활성화됩니다. 클릭하면 진열 전 최종 확인 팝업(5번)이 나타납니다.
5
진열 전 최종 확인 팝업
[추가] 버튼을 누르면 나타납니다. 어떤 섹션에 몇 개를 추가하는지 확인하고 [진열하기]로 확정합니다.
1
2
3
사용 방법
1
섹션명·추가 개수 확인
의도한 섹션이 맞는지, 개수가 올바른지 체크하세요.
2
[취소]로 이전 단계 복귀
이전 체크 상태가 유지됩니다.
3
[진열하기]로 확정
완료 팝업이 나타나고 진열 목록에 추가됩니다. 이후 [적용]까지 눌러야 최종 저장됩니다.
6
진열 완료 & 마무리 정리
초록색 완료 팝업이 나타나면 추가 완료입니다. [확인] 후 순서와 공개 설정을 다듬고 하단 [적용]으로 최종 저장.
1
2
3
사용 방법
1
완료 팝업에서 [확인] 클릭
초록 체크 팝업이 나타나면 추가 완료입니다. [확인]을 클릭하면 좌측 목록에 상품이 반영됩니다.
2
순서·공개 설정 조정
추가된 상품은 목록 맨 아래에 위치합니다. ⠿ 드래그로 순서를 조정하고, 바로 노출하지 않을 상품은 비공개로 설정하세요.
3
하단 [적용]으로 최종 저장
적용 없이 페이지를 닫으면 변경사항이 모두 사라집니다.
✅ 완료 체크리스트
원하는 상품이 모두 추가됐나요? · 순서가 올바른가요? · 비공개 설정 했나요? · [적용] 눌렀나요?
